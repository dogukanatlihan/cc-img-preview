# Security

cc-img runs on your machine inside Claude Code. It reads image files, runs the system's image programs on them, and opens files when you click. A fault in any of those can be a security problem.

Report one privately: [open a security advisory](https://github.com/dogukanatlihan/cc-img-preview/security/advisories/new). Do not open a public issue for it.

Say what an attacker controls (a file name, an image, a command's output), what happens, and the steps that make it happen.

Only the latest version gets fixes.
